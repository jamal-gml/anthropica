# Frontend Development

1. Identify framework, routing, component library and styling approach from existing files.
2. Find the closest existing component or page pattern.
3. Confirm data contract and state ownership before changing UI.
4. Implement only the requested interaction and states.
5. Include loading, empty, error and success states where relevant.
6. Preserve responsive layout, keyboard access and semantic markup.
7. Run targeted lint, typecheck and tests.
8. Inspect the final diff; do not reformat unrelated files.

Do not invent APIs or mock production data unless explicitly requested.
