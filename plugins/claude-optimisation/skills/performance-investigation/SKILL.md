# Performance Investigation

1. Define the symptom, affected workload and target metric.
2. Establish a baseline before changing code.
3. Profile or inspect the relevant execution path.
4. Identify the measured bottleneck.
5. Propose the smallest change with an expected measurable effect.
6. Benchmark under comparable conditions.
7. Report before/after results and trade-offs.

Do not optimise based only on intuition. Avoid broad rewrites without evidence.
