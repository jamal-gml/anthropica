# SEO Content

## Intent first
- Identify the primary query and its search intent: informational, commercial, transactional or navigational.
- Describe what currently ranks (format, depth, angle) when that data is available. Match the format the intent demands; differentiate on usefulness.
- Never invent search volumes or difficulty scores. Use provided tool data or mark figures as estimates.

## Content brief
```
Primary query and intent:
Secondary queries and questions to answer:
Audience and their goal:
Angle / unique value (data, expertise, examples competitors lack):
Outline (H2/H3):
Internal links to add (from and to):
Title tag and meta description drafts:
Schema type:
Call to action:
```

## On-page optimisation
- Title tag: primary topic near the start, compelling, about 50–60 characters. Meta description: a benefit and a reason to click, about 150–160 characters.
- One H1 matching the intent; descriptive H2s that answer real questions. Answer the core question early.
- Use the topic's natural vocabulary; no keyword stuffing.
- Show experience and expertise (E-E-A-T): author bylines, first-hand detail, sources cited, dates updated.
- Descriptive internal anchors to and from related pages. Link out to authoritative sources where it helps the reader.
- Images with descriptive file names and alt text. FAQ or HowTo structured data only where the content genuinely matches.

## Topic clusters
A pillar page covering the broad topic, and cluster pages for specific subtopics, all linking to the pillar and to each other where relevant. Avoid several pages competing for the same query (cannibalisation); merge or differentiate them.

## Refreshing content
Prioritise pages with declining traffic or impressions: update facts and dates, fill gaps against current results, improve the intro and structure, fix broken links, and re-promote.

## Output
The brief or optimised content, the title and meta drafts, the internal linking plan, and the assumptions about intent and data.
