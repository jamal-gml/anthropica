# Marketing pack (`anthropica-marketing`)

> Generated by `scripts/build.py` from `packs.json`. Do not edit files in this folder; edit `skills/`, `agents/` or `packs.json` and rebuild.

For: Marketing, content and growth teams. On-brand marketing copy, campaign planning and measurement, and search-friendly content.

## Install

```text
/plugin marketplace add jamal-gml/anthropica
/plugin install anthropica-marketing@anthropica
```

Claude loads a skill automatically when a task matches its description. Invoke one directly with its slash command.
Skills are named `<phase>-<topic>`. Start with `/anthropica-marketing:workflow` to see the phases and get a suggested next skill;
each skill also ends with a pointer to the next phase.
