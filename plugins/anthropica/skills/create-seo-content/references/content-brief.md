SERP features present: featured snippet (type: paragraph/list/table), people-also-ask (list the questions), video, images, local pack, shopping, forums/discussions, news.

Read the pattern:
- 7+ of 10 results share a page type -> that's the required format.
- Forums/discussions ranking -> searchers want first-hand experience; add real experience and opinions.
- Mostly big brands with thin pages -> beatable with depth and evidence; mostly specialist deep pages -> needs real expertise and original assets.
- Results updated recently -> freshness matters; plan a maintenance cadence.
- Mixed intents -> the query is ambiguous; serve the dominant intent and link to a page for the other.

## Keyword clustering
1. Collect candidate queries (tool export, Search Console queries, people-also-ask, related searches, customer language).
2. Remove off-intent, navigational-for-others and irrelevant terms.
3. Group by SERP overlap: queries sharing ~3+ top-10 URLs -> one page; little overlap -> separate pages, even if the words look similar.
4. Name each cluster by its head query; pick a primary and up to ~10 secondaries.
5. Map to URL: existing page that already ranks/gets impressions for it > new page. One cluster per URL.
6. Build hub-and-spoke: pillar (broad topic) links to every cluster page; cluster pages link back to the pillar and to closely related siblings.

## Content types and what they need
| Type | Must include |
|---|---|
| How-to guide | Prerequisites, numbered steps, screenshots, expected result, troubleshooting |
| Comparison / "X vs Y" | Criteria stated up front, a summary table, honest trade-offs, who each option suits, disclosure of own product bias |
| "Best X" list | Selection method, hands-on evidence per item, who each item is for, last-tested date |
| Definition / explainer | One-sentence definition first, example, related concepts, common misconceptions |
| Product/category page | Unique description (not manufacturer copy), specs, price/availability, reviews (real), FAQs from support |
| Location page | Real address/contact, local details, local reviews; no city-swap duplicates |
| Programmatic pages | Each page has unique data that answers the query; otherwise don't publish them |
