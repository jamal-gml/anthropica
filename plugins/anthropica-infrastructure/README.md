# Infrastructure pack (`anthropica-infrastructure`)

> Generated by `scripts/build.py` from `packs.json`. Do not edit files in this folder; edit `skills/`, `agents/` or `packs.json` and rebuild.

For: Infrastructure, cloud and site reliability engineers. Infrastructure as code, Kubernetes, observability, incident response, architecture and GitHub workflow standards.

## Install

```text
/plugin marketplace add jamal-gml/anthropica
/plugin install anthropica-infrastructure@anthropica
```

Claude loads a skill automatically when a task matches its description. Invoke one directly with its slash command.
