# Infrastructure pack (`anthropica-infrastructure`)

> Generated by `scripts/build.py` from `packs.json`. Do not edit files in this folder; edit `skills/`, `agents/` or `packs.json` and rebuild.

For: Infrastructure, cloud and site reliability engineers. Infrastructure as code, Kubernetes, observability, incident response, architecture and GitHub workflow standards.

## Install

```text
/plugin marketplace add jamal-gml/anthropica
/plugin install anthropica-infrastructure@anthropica
```

Claude loads a skill automatically when a task matches its description. Invoke one directly with its slash command.
Skills are named `<phase>-<topic>`. Start with `/anthropica-infrastructure:workflow` to see the phases and get a suggested next skill;
each skill also ends with a pointer to the next phase.

## Agents

| Agent | Role |
|---|---|
| `architect` | Evaluates system design, boundaries, data flow, trade-offs and phased implementation plans. Use for design decisions, migrations or features that span several modules, before any code is written. |
| `code-reviewer` | Reviews a diff for correctness, regressions, maintainability and test gaps. Use after a change is implemented and before it is committed or merged. |
| `security-reviewer` | Reviews code and configuration for realistic vulnerabilities and trust-boundary failures. Use when a change touches authentication, authorisation, user input, secrets, file handling, dependencies or infrastructure config. |
